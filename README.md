# SQL Student Management System

## Project Description
A simple Student Management System built using SQL Server.

## Features
- Create Student Table
- Create Courses Table
- Create Enrollment Table
- Insert Records
- Update Student Marks
- Delete Student Records
- Find Topper
- Find Second Highest Marks
- Count Students Branch-Wise
- INNER JOIN Queries
- Create Views
- Create Indexes

## Technologies Used
- SQL Server
- T-SQL
